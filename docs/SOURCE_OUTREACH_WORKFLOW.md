# Kontakt ze źródłami — proces redakcyjny

1. Katalog źródeł wskazuje kanały zablokowane lub wymagające kontaktu.
2. Redaktor tworzy kartę kontaktu z konkretnym pytaniem o RSS, API, licencję albo dopuszczalny zakres archiwizacji.
3. Wiadomość jest wysyłana ręcznie z redakcyjnej skrzynki po zatwierdzeniu przez właściciela projektu.
4. Odpowiedź i zakres zgody są zapisane przy źródle.
5. Harwester uruchamia się dopiero po technicznym i redakcyjnym zatwierdzeniu kanału.

Nie wysyłamy seryjnych wiadomości bez przeglądu, nie traktujemy braku odpowiedzi jako zgody i nie obchodzimy zabezpieczeń źródła.
