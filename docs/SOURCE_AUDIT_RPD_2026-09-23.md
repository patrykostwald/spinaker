# Audyt źródła: Rzecznik Praw Dziecka

Data kontroli: 23 września 2026 r.

## Wynik techniczny

- Oficjalny kanał aktualności `https://brpd.gov.pl/feed/` odpowiada poprawnym RSS XML.
- Oficjalny BIP `https://bip.brpd.gov.pl/` jest dostępny i udostępnia własne API WordPress, ale nie jest podstawą do pobierania wpisów bez odrębnej karty.

## Decyzja

**Nie aktywować harvestera.** W trakcie tej kontroli nie znaleziono opublikowanych, jednoznacznych warunków ponownego wykorzystania dla kanału aktualności RPD. Sama dostępność RSS nie wystarcza do utworzenia karty dostępu.

## Następny krok

Zostawić RPD jako nieaktywnego kandydata. Do aktywacji potrzebne są: link do warunków ponownego wykorzystania obejmujących ten kanał albo pisemne potwierdzenie wydawcy. Ewentualna karta może obejmować wyłącznie tytuł, datę, krótki opis kanału i link do oryginału; bez pełnej treści i bez obrazów.
