# Zablokowany zakres MVP — baza i redakcyjne nitki

## Priorytet bieżący

Najpierw budujemy legalną, audytowalną bazę. Każde źródło przechodzi sekwencję:
audyt → zatwierdzona metoda → ograniczony pilot → mierzalny przyrost boxów →
stała pula harvestera. Błąd bez przyrostu zatrzymuje źródło i otwiera diagnozę,
nie kolejne retry.

## MVP

- Boxy, źródła, daty, linki, metody pozyskania i powiązane nitki.
- Jedna lub dwie redakcyjnie zatwierdzone nitki Dr Spina dziennie.
- Dr Spin w MVP jest pracą redakcyjną opartą o bazę i źródła, nie publicznym
  automatem do dowolnych URL-i.

## Po MVP / faza 2

- Wklejanie URL-i postów przez użytkownika i analiza Dr Spina na żądanie.
- Integracja oficjalnego API X dla zatwierdzonej listy kont polityków.
- Alerty o nowych postach do redakcji; człowiek wybiera materiał i może
  przekazać go do przygotowania nitki.
- Panel redakcyjny, konta użytkowników oraz pozostałe elementy frontendu.
