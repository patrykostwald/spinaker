# Organizacje i relacje osób publicznych

## Cel

Rejestr pokazuje wyłącznie możliwe do sprawdzenia, publiczne relacje osoby publicznej z fundacją, stowarzyszeniem, spółką lub innym podmiotem. Nie jest narzędziem do wyszukiwania prywatnych danych ani automatycznego łączenia ludzi o tym samym imieniu i nazwisku.

## Dane widoczne w przyszłym profilu

- nazwa podmiotu i jego rodzaj,
- numer KRS,
- publicznie wskazana rola,
- relacja obecna albo historyczna,
- link do dowodu publicznego i data sprawdzenia,
- stan: potwierdzona albo wymaga potwierdzenia redakcji.

Nie przechowujemy ani nie pokazujemy adresów, PESEL-i, dat urodzenia, prywatnych telefonów, prywatnych adresów e-mail ani danych osób niepublicznych.

## Zasada identyfikacji

Zbieżność imienia i nazwiska **nie wystarcza**. Relację wolno utworzyć wyłącznie wtedy, gdy bezpośredni publiczny dowód pozwala rozpoznać właściwą osobę, na przykład oficjalny profil podmiotu, oświadczenie majątkowe, strona Sejmu, komunikat instytucji albo wpis w rejestrze wraz z dodatkowym potwierdzeniem.

## Praca redakcyjna

1. Redaktor tworzy podmiot z nazwą, 10-cyfrowym KRS, typem i linkiem do oficjalnego rejestru.
2. Dodaje relację jako `wymaga potwierdzenia redakcji`, z rolą, statusem obecna/historyczna i bezpośrednim linkiem do dowodu.
3. Drugi redaktor sprawdza źródło oraz tożsamość osoby.
4. Dopiero potem relacja dostaje stan `potwierdzona`, datę i redaktora zatwierdzającego.
5. Błędną relację oznacza się jako odrzuconą; nie usuwa się historii bez śladu.

W panelu administracyjnym są osobne listy podmiotów i relacji oraz działania „potwierdź” i „odrzuć”.

## Import z KRS

Pierwszy etap jest ręczny i dotyczy małej, reprezentatywnej próbki liderów partii oraz członków rządu. Automatyczny import z oficjalnego API KRS może później uzupełniać dane podmiotów, lecz nie może automatycznie tworzyć relacji osoba → podmiot. Każda taka relacja nadal wymaga dowodu i zatwierdzenia redakcji.

## Kontrola jakości

- link dowodowy musi prowadzić do publicznego źródła;
- potwierdzenie wymaga daty oraz użytkownika redakcyjnego;
- prezentacja publiczna pokaże tylko potwierdzone relacje;
- informacje historyczne pozostają oznaczone jako historyczne;
- zgłoszenie błędu będzie kierowane do moderacji.
