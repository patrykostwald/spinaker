# Security policy

Please report vulnerabilities privately to kontakt@iapply.pl with "security" in the subject. Include steps to reproduce and the affected URL or file. We acknowledge reports within three working days and keep you informed until a fix ships.

Do not open public issues for security problems, and do not test against production in ways that affect other users or their data.

Secrets are never committed to this repository. If you find one, report it the same way and we will rotate it immediately.
